# boids

A simple 2D boid simulation

![](./Screencast_20260515_143710.gif)

## Building & running

Ensure you have CMake installed.
Ensure you have [SDL build dependencies](https://wiki.libsdl.org/SDL3/README-linux) installed.

```sh
cmake -S . -B build # Setup build directory
cmake --build build # Build
./build/project # Run
```
